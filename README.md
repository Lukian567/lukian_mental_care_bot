# mental care bot

This is my learning portfolio project, an end to end pet project where I wanted to use everyting I learned on my courses in a real situation, not only in exercises, so here you can find Python, SQL, Google Sheets, visualization in Tableau, and later my own written analysis of the dashboard.

The idea is a Telegram bot for a daily mental check in. Every day the bot asks me a few short questions in the morning and in the evening, it takes around thirty or forty five seconds and everything is done with buttons, so there is no long writing. In the morning it asks about sleep hours, sleep quality, mood, inner resistance, anxiety, a first thought and one small action for the day, and in the evening about activities, mood, did I do the morning action, social energy, the main emotion with its strength and a short closing thought. Most answers use a scale from one to five becuase it keeps the data clean and easy to compare.

The bot is written in Python with aiogram, PostgreSQL and SQLAlchemy, and I want to be honest here, I made only the Python part with the help of AI, it was my coding assistant, but I tested and ran everything myself. The SQL, the Tableau dashboard and the visualization work I did myself. Every check in is saved in the database as one row, and if I do the same check in again for the same day, the bot updates the old answer and does not create a duplicate.

For the analysis I wrote an SQL view that joins the morning and the evening into one row for one day, and adds some calculated fields like mood change during the day, sleep score, distress score and a flag for short sleep, less than seven hours. The code is in the sql folder. Every night at five to midnight the bot sends this data to a Google Sheet, Tableau reads it from there. I chose Google Sheets because it is easy to sync and it works well for a private user who wants to keep a Tableau Public dashboard updated, and I refresh the dashboard by hand about once a month.

The dashbord is published on Tableau Public, [HERE](https://public.tableau.com/views/morning_care_bot/Dashboardv3Warm?:language=en-US&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link), it has key numbers on the top, donut charts, a comparison of workdays and weekends, a chart of morning and evening mood and a few more, with filters by date and by user.

One important thing, the data in the dashboard is synthetic, I created it with SQL script for the summer months to build the dashboard before I had real data, so the patterns inside are only a demo and they are not real conclusions. The data was generated with the help of AI, so some charts, for example the mood lines, look too simple and do not follow real human behaviour, and this is expected. I started this project for myself, so the bot questions and answers are in Ukrainian for now, and some values in the dashboard, like emotions and social state, are also in Ukrainian. Later I want to rework it and add English and Polish. The bot is not on a server yet, it runs locally on my laptop. To run it, copy .env.example to .env and fill in your values, install the packages with pip install -r requirements.txt and start the bot with python -m bot.main.
